# S00 Foundation: repo, toolchain, pins, generators, lints

Version 1.0.1, 2026-10-30. Depends on: DESIGN.md, S09. Blocks: everything.

## 1. Purpose

Create the empty, buildable, lint-gated project every other spec lands in. After S00 the repo builds a page that shows the right ground color and the Commit Mono "Justin Poli" text from generated copy, and every gate in S11 can run (most will fail until later specs land; the harness must exist first).

## 4. Generators (write these first)

### 4.1 `tools/extract-tokens.mjs`

Reads `spec/astryx/DESIGN.md`, finds the single fenced block whose info string is exactly `json design-tokens`, parses it, and writes:

- `src/tokens.generated.ts`: `export const T = <object> as const;` plus a header comment `// GENERATED from spec/astryx/DESIGN.md v<version>. Do not edit.`
- `themes/lane/tokens.generated.json`: the same object.
- `src/styles/tokens.generated.css`: the `--jp-*` custom properties (regime colors as `--jp-void-ground` etc., type display tokens, gutters, keymap heights, durations as `--jp-duration-travel` etc., easings as `--jp-ease-signature`).

Fails (exit 1) if the block is missing, is not valid JSON, or `world.laneCount !== world.server.sm.count * 128`.

### 4.2 `tools/extract-copy.mjs`

Reads `spec/astryx/specs/S09-copy-deck.md` section 4 table, writes `src/copy.ts` exporting `C` keyed by ID (`C['C-SRV-H1']`), with links as `{label, href}`. Fails on duplicate IDs.

### 4.3 npm scripts (exact names)

```
"gen": "node tools/extract-tokens.mjs && node tools/extract-copy.mjs && node tools/copy-fonts.mjs",
"theme": "astryx theme build themes/lane/laneTheme.mjs --out themes/lane/dist/lane.css",
"theme:check": "astryx theme build themes/lane/laneTheme.mjs --out themes/lane/dist/lane.css --check",
"dev": "npm run gen && vite",
"build": "npm run gen && npm run theme && tsc --noEmit && vite build && node tools/prerender.mjs",
"lint": "node tools/lint-tokens.mjs && node tools/banned-scan.mjs src && python3 -I tools/palette-receipt.py spec/astryx/DESIGN.md",
"test": "playwright test",
"gates": "npm run build && npm run lint && npm run theme:check && node tools/banned-scan.mjs dist && playwright test"
```

## 5. Lints

### 5.1 `tools/lint-tokens.mjs` (G-TOKENS)

Scans `src/**/*.{ts,tsx,css,glsl}` excluding `*.generated.*`. Fails on any of:
- a hex color literal `#[0-9a-fA-F]{3,8}\b`
- a duration literal `\b\d+(\.\d+)?m?s\b` in CSS or in TS strings
- `cubic-bezier(` outside generated files
- in `src/world/**/*.ts`, any numeric literal other than `0`, `1`, `2`, `0.5`, `-1` that is not inside an array index or loop bound, unless the line carries `// lit-ok: <reason>` (reviewed in code review)
- `--duration-medium-max` anywhere
- `box-shadow` with a non-inset value, `backdrop-filter`, `filter: blur`, `linear-gradient`, `radial-gradient`, `text-transform: uppercase`

### 5.2 `tools/banned-scan.mjs` and `tools/banned.txt`

`banned.txt`, one pattern per line, case-insensitive: `passionate`, `leverage`, `cutting-edge`, `seamless`, `delve`, `tapestry`, `ninja`, `rockstar`, `showcase`, `robust`, `elevate`, `unlock`, `journey`, `\bactually\b`, `\bGPA\b`, `2\.77`, `631`, `835-5490`, `CanonClaw`, `\bASH\b`, `Nexus`, `GRPO`, `Oracle`, `\blive\b`, `\bonline\b`, `uptime`, `tokens/s`, `tok/s`, plus the two dash characters U+2013 and U+2014. Exception: two LeafLink strings describe the product with "live" by brief (C-LL-STACK, C-LL-P1); the scanner allows the exact substrings `WebSocket live feed` and `on a live map` and nothing else containing "live". The word never describes the server or the site. Scanning `dist/` scans text content of HTML and string literals of JS (use a simple extraction: everything between quotes or between tags).

## 6. CSS layer order (global.css, first line)

```css
@layer reset, astryx-base, astryx-theme, jp-tokens, jp-regime, jp-chrome;
```
`@astryxdesign/core/reset.css` and `@astryxdesign/core/astryx.css` are imported into their layers; the theme CSS is already layered by `astryx theme build`; site styles go only in `jp-chrome`; regime overrides only in `jp-regime`. No unlayered CSS (an unlayered rule beats every layer and silently overrides Astryx; G-TOKENS greps for rules outside `@layer` blocks).

## 7. HTML template essentials (index.html)

- `<html lang="en" data-regime="void" style="color-scheme: dark">`; `data-astryx-theme="lane"` on `<body>` (theme CSS is scoped to that attribute).
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
- `<link rel="preload" href="/fonts/commit-mono-latin-400-normal.woff2" as="font" type="font/woff2" crossorigin>`
- `<meta name="theme-color">` set per regime ground by travel.
- Inline critical CSS: body background `var(--jp-ground)`, ground values for all three regimes, so the first paint is the correct color before any JS.
- `<div id="world" aria-hidden="true">` (canvas mount, fixed, inset 0, z-index 0, `pointer-events` managed by scene) then `<div id="root">` (React, z-index 1).

## 8. Kill criteria

- K-S00-1: any dependency without an exact pin, or `package-lock.json` missing.
- K-S00-2: generated files edited by hand (`npm run gen` changes them; CI runs gen and fails on a dirty tree).
- K-S00-3: `npm run build` takes more than 60s on CI hardware (signals a runaway generator).
